# Changelog

Release notes for Kinetra, newest first. A stable release vX.Y.Z uses its "X.Y.Z" section below
as the update notes (shown in Help › Check for updates); canary builds use the "Unreleased"
section when it has text, else the commit subjects. See docs/RELEASING.md.

Written for Kinetra's users (what they gain, not internal changes) and shown as plain text in the
update panel: one paragraph per line, no Markdown.

## Unreleased

A fresh look: Kinetra has a new logo, and Canary builds now carry a yellow CANARY badge so you always know you're on the preview channel.

See your graphic right away: open a template and it's already showing in the preview. Pick an image or type a name and watch it update live; Play in still shows the full animation.

A tidier template editor: templates with many looks no longer crowd the editor on smaller screens. The looks scroll neatly, and the preview always stays in view.
